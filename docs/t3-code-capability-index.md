# T3 Code feature flags and integration variants

This index records integration variants in the pinned T3 Code source. Reproduce each variant on its applicable host and client surfaces. Store the result and real-account evidence with the owning issue. The source index uses the pin and the CLI behavior reference remains v0.1.11.

## Feature flags

The host parses `T3CODE_FEATURE_FLAGS` once at startup. Test unset, enabled, disabled, invalid, and changed-with-restart cases. Bare names enable Boolean flags. The invalid configuration case falls back to the default configuration. [Flag contract](https://github.com/pingdotgg/t3code/blob/431da7f4e55b82b386e68a9f32c543fac2efedf5/packages/shared/src/FeatureFlags.ts#L9) · [Reference tests](https://github.com/pingdotgg/t3code/blob/431da7f4e55b82b386e68a9f32c543fac2efedf5/packages/shared/src/FeatureFlags.test.ts)
